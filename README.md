# ML from Scratch

Core machine learning algorithms implemented from first principles in NumPy,
by an applied mathematician moving into ML and optimization.

## Planned
- [ ] Least squares (normal equations, QR, lstsq)
- [ ] Linear regression with gradient descent
- [ ] Logistic regression
- [ ] PCA via SVD
- [ ] K-means clustering
- [ ] Small neural network with backpropagation

Each implementation is verified against NumPy or scikit-learn.
